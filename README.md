# KiCad PCB Projects

A collection of PCB designs created in **KiCad**, built as hands-on practice in
schematic capture, board layout and fabrication-ready output.

## Projects

Each folder in this repository is a separate PCB project. Open a folder to see
its schematic, PCB layout and fabrication files.

## Repository Structure

```
kicad-pcb-projects/
├── README.md
├── .gitignore
├── <project-name>/
│   ├── <project-name>.kicad_pro
│   ├── <project-name>.kicad_sch
│   ├── <project-name>.kicad_pcb
│   └── fabrication/
└── ...
```

## How to Open a Project

1. Install [KiCad](https://www.kicad.org/download/)
2. Clone the repository:
```bash
   git clone https://github.com/SattwikHiwale/kicad-pcb-projects.git
```
3. Open the `.kicad_pro` file inside any project folder
